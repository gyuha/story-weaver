# StoryWeaver

AI가 작가의 세계관·캐릭터·설정을 기억하고 집필을 보조하는 웹 기반 웹소설 창작 SaaS의 도메인 용어집.

## Language

**작품 (Work)**:
한 명의 작가가 집필하는 하나의 소설 프로젝트. 모든 설정·플롯·원고의 최상위 소유 단위.
_Avoid_: 프로젝트, 책, 소설(파일)

**World Bible**:
한 작품의 모든 설정(인물·장소·사건·아이템 등)을 저장·관리하는 설정 저장소. "기억하는 AI"의 근거 데이터.
_Avoid_: 설정집, 위키, 노트

**엔티티 카드 (Entity Card)**:
World Bible 안의 한 항목(인물·장소·사건·아이템 중 하나)을 표현하는 정형 데이터 단위. 정해진 필드(이름·속성 등)를 가진다.
_Avoid_: 설정 항목, 노드, 문서

**타임라인 상태 (Timeline State)**:
한 엔티티가 특정 시점(챕터/씬)에 갖는 상태. "3화에서 사망", "5화에서 각성"처럼 시간에 따라 변하는 사실을 기록해 상태 추적과 설정 충돌 감지의 근거가 된다.
_Avoid_: 히스토리, 로그, 변경 이력

**씬 (Scene)**:
집필과 AI 생성의 최소 단위. `작품 → 에피소드 → 챕터 → 씬` 계층의 말단. (시놉시스는 이 계층의 한 단계가 아니라 작품 직속 요약 텍스트다 — 데이터 모델은 `docs/data-model.md` 참조.)
_Avoid_: 장면, 문단, 블록

**씬-엔티티 링크 (Scene-Entity Link)**:
특정 씬에 어떤 엔티티가 등장하는지를 명시하는 연결. 메모리가 무엇을 불러올지 정하는 1차 근거(벡터 유사도는 보조).
_Avoid_: 태그, 참조

**메모리 (Memory)**:
현재 집필 중인 씬과 관련된 World Bible 설정을 찾아 AI에게 컨텍스트로 제공하는 작업·그 결과. 정형 카드 + 벡터 검색 + 씬-엔티티 링크의 하이브리드로 구성된다.
_Avoid_: RAG (사용자 대면 UI·문구에서는 '메모리'를 쓰고 RAG는 피함; 내부 설계 문서에서는 RAG를 그대로 사용 가능), 컨텍스트 주입

**채팅 (Chat)**:
집필 화면 우측 패널에서 작품에 대해 자유롭게 묻고 답하는 기능. 대화는 씬이 아니라 **작품 단위**로 이어진다(씬을 옮겨도 유지). 매 턴 현재 화(챕터) 원고 전문 + [[메모리]] 검색 결과로 컨텍스트를 새로 조립해 최신 집필 내용을 반영한다(고정 시스템 프롬프트가 아님). "새 대화 시작"으로 리셋할 수 있으나 과거 대화 재열람은 별도 범위.
_Avoid_: Q&A, 상담 (코드 식별자는 chat 유지)

**모델 스위칭 (Model Switching)**:
집필 작업의 종류(이어쓰기·교정·구조 생성 등)에 따라 저비용/고품질 LLM을 골라 호출하는 전략.
_Avoid_: 모델 라우팅, 폴백

**품질 티어 (Quality Tier)**:
사용자가 설정 화면에서 작품 전체에 적용하는 생성 품질 수준(저비용/균형/고품질). [[모델 스위칭]]이 이 티어를 기준으로 삼아 작업별 모델을 자동 선택한다. 사용자는 구체 모델명·API 키를 직접 다루지 않는다(BYOK 아님 — 키는 서버가 보유).
_Avoid_: 플랜, 등급, 모델 선택, BYOK

**읽기 모드 (Reading Mode)**:
작가가 자신의 원고를 독자처럼 연속으로 읽는 read-only 검토 뷰. [[씬]] 경계와 AI·메모리·작업 크롬을 모두 걷어내고 챕터(=화) 단위로 본문만 보여준다. **편집 모드**(집필 화면)와 짝을 이루는 별개 모드이며, 외부 독자 대상 퍼블리싱·연재가 아니라 작가 본인의 흐름·오탈자 점검 용도다.
_Avoid_: 미리보기, 독자 뷰, 뷰어 (랜딩의 독자용 "읽기"와 혼동 금지)

**편집 모드 (Edit Mode)**:
원고를 작성·수정하는 집필 화면(`write`). 씬 1개 단위로 AI 이어쓰기·메모리 패널·작업트리를 함께 제공한다. [[읽기 모드]]와 대비되는 짝.
_Avoid_: 작성 모드 (코드 식별자는 기존대로 `write`/'집필' 유지)

**부 (Part)**:
한 작품을 큰 서사 단위로 나눈 묶음(예: 제1부 청운문편, 제2부 혈산문편). `작품 → 부 → 화(=챕터) → 씬` 계층에서 작품 바로 아래 단계다. `docs/data-model.md`가 정본 계층에서 **에피소드(Episode)**로 부르던 그 자리이며, 사용자 대면 명칭을 "부"로 통일한다(코드/DB 식별자 `episode*`는 당분간 유지 — `write`/'집필' 선례와 동일). web 코드에서는 각 챕터에 박힌 자유 문자열 `partLabel`로 표현된다.
_Avoid_: 에피소드(사용자 대면), 편, 장, 시즌

**화 (= 챕터 / Chapter)**:
부 안의 한 회차. 사용자 대면 명칭은 "N화"(예: 6화), 코드/도메인 식별자는 `Chapter`이며 `index`가 화 번호다. 다수의 [[씬]]을 가진다.
_Avoid_: 회차(코드), 에피소드

**버전 기록 (Version History)**:
한 [[씬]]의 본문이 **작가의 집필 시간축**을 따라 저장돼 온 스냅샷들의 기록. 시간대별로 과거 버전을 읽고, 현재 버전으로 덮어쓰며(현재로 보내기), 변경분을 비교할 수 있다. 편집은 현재 버전만 가능하고 과거 버전은 읽기 전용이다. **타임라인 상태와 다른 축이다** — 타임라인 상태는 엔티티가 *작중 시점*(3화 사망 등)에 갖는 상태이고, 버전 기록은 *원고가 실제로 고쳐져 온 이력*이다.
_Avoid_: 히스토리, 타임라인(타임라인 상태와 혼동 금지), 리비전

**관리자 (Admin)**:
서비스 운영자 역할(role `ADMIN`). [[계정 승인]]과 운영 통계 조회 권한을 가지며, 작품을 소유·집필하는 **작가**와 구분되는 별개 역할이다. 한 계정이 둘을 겸할 수 있으나 개념은 분리한다.
_Avoid_: 슈퍼유저, 운영자(코드 식별자), 매니저

**계정 승인 (Account Approval)**:
회원 가입한 계정에 [[관리자]]가 서비스 사용 허가를 부여하는 절차. 초기 테스트 기간 동안 승인된 계정만 서비스를 쓸 수 있게 하는 게이팅 수단이다. 계정 상태는 `대기(pending) → 승인(approved)` 또는 `거부(rejected)`로 전이한다. (이메일 인증·정지와 다른 축 — 이메일 인증은 본인 확인, 승인은 운영자 허가다.)
_Avoid_: 가입 승인, 활성화, 인증(이메일 인증과 혼동 금지)

**회원 (Member)**:
가입한 한 계정을 [[관리자]] 관점에서 부르는 말 — 승인 대상 목록·통계의 단위. 집필 맥락의 "작가"와 같은 사람을 가리키되, 관리 화면에서는 작품 소유자가 아니라 *승인·집계 대상 계정*으로 본다.
_Avoid_: 유저, 가입자
