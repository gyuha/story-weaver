# 연령·수위 제한을 제품에서 제거하고 정책 집행을 모델 제공자에게 위임

ADR-0003은 "상용 LLM API(Claude/GPT) 하이브리드"를 전제로 생성 수위를 전체이용가(약 15세)로 묶었다. **그 전제가 사라졌다** — 프로바이더가 자체 호스팅 OpenAI 호환 라우터로 바뀌었고(`LLM_PROVIDER=openai_compatible`), 동시에 수위 가드의 구현이 한국어에서 실패했다: S1 키워드 가드가 단순 부분 문자열 매칭(`keyword in text`)이라 `보지`가 **"뒤를 돌아보지 마십시오"**·"보지 못했다"에, `자지`가 "잠을 자지 않았다"에, `사정`이 "사정이 있다"에 걸려 **평범한 소설 원고에서 AI 기능 전체가 차단**됐다(가드는 assist·chat·works·manuscript·image_generation·dynamic_update 6곳에서 쓰인다).

**결정: 제품이 강제하는 연령·수위 제한을 전부 제거한다.** moderation 도메인의 S1 키워드 선제 가드와 S2 완화 재시도를 없애고, 프롬프트에 박힌 "전체이용가(약 15세) 수위를 지키세요" 지시 3곳(`prompt_assembler.py`·`chat_context_service.py`·`manuscript_router.py`)과 이미지 프롬프트 가드도 제거한다. 콘텐츠 정책의 집행은 **모델 제공자에게 위임**하고, 제공자가 거절하면 완곡하게 위장하거나 자동으로 순화하지 않고 **"모델이 생성을 거절했다"고 사실대로 알린다**. 운영 오류 분류(`_OPERATIONAL_LLM_ERRORS` → `LLMUnavailableError`)는 수위와 무관한 인프라 기능이므로 유지한다.

## Considered Options

- **우리 층의 제한 전부 제거 (채택)** — 오탐의 원인(자체 키워드 매칭)을 제거하고 정책 경계를 한 곳(모델 제공자)으로 단일화한다. 작가가 쓴 수위를 시스템이 낮추지 않는다.
- **오탐만 제거** — 충돌 키워드(`보지`·`자지`·`사정`)만 목록에서 빼기. 가장 짧지만 한국어에서 부분 문자열 매칭은 근본적으로 취약해 다른 키워드로 같은 사고가 재발하고, 프롬프트의 수위 지시가 남아 생성이 계속 억제된다.
- **성인물 지원 완주** — 무검열 모델 배선 + 연령 인증까지. 이 ADR의 범위를 넘고 여러 사이클이 필요하다. 별도 결정으로 남긴다.

## Consequences

- **"제한 없음"이 "무엇이든 생성됨"을 뜻하지 않는다.** 현재 모델(`cx/gpt-5.6-terra` = 상용 gpt-5.6)은 노골적 성적 묘사를 제공자 차원에서 거절한다. 실제로 19금을 쓰려면 모델을 바꿔야 하며, 그것은 별도 결정이다.
- **서비스로 공개해 성인물을 다루려면 연령 인증이 별도로 필요하다**(청소년보호법상 청소년유해매체물 취급). 이 ADR은 연령 인증을 다루지 않는다 — ADR-0003이 요구했던 "모델·정책·연령인증" 중 **모델·정책만** 재설계한 것이다.
- moderation 도메인의 책임이 "수위 완곡 처리"에서 **"LLM 호출 실패 분류"**로 축소된다. 도메인 이름이 부적절해지지만 리네임은 import 전반을 건드려 비용이 크므로 이름은 유지하고 docstring으로 책임 변경을 기록한다.
- 자동 완화 재시도(`SOFTENED_NOTICE`)가 사라져 **생성 성공률이 내려간다** — 제공자가 거절하면 그대로 거절로 끝난다. 작가가 표현을 직접 조정하는 것이 의도된 흐름이다.
- **ADR-0003을 전체 대체한다** — 그 ADR의 두 결정(상용 API 하이브리드 / 전체이용가 수위) 모두 더 이상 유효하지 않다. 실제 은퇴 처리(`adr/retired/`로 이동)는 fg-cleanup의 몫이다.
- `docs/ai-pipeline.md` 6장·`docs/image-generation.md` 4장이 수위 가드를 전제로 기술하고 있어 문서와 코드가 어긋난다. 문서 갱신은 이 결정의 후속이다.
