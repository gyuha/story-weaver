## 배운 것

**다음에 다르게 할 것**

- **타입 검사가 범위 침범을 막을 수 있다.** `mypy`의 `Missing positional argument`가 "비목표 경로를 건드리려 한다"는 신호였다. 강제 인자 대신 `None` 분기로 돌아선 것이 옳았다 — 타입 에러를 "고쳐야 할 것"으로만 보지 말고 **설계가 범위를 넘었다는 신호**로 읽을 것.
- **part를 연달아 실행하기 전에 앞 part를 커밋할 것.** Run all 절차에 커밋 지점이 없어 워킹트리가 섞였고, 검증 담당이 스코프를 수동으로 방어해야 했다. 커밋해 두면 각 part의 diff가 깨끗하게 분리된다.
- **상수 테이블은 "값이 있다"가 아니라 "값이 흘러간다"를 테스트해야 한다.** 배선을 끊으니 `assert 1.0 == 0.7`로 red가 됐다 — 표만 단언하는 테스트였다면 배선이 끊겨도 green이었을 것이다(task 82가 인용한 #71의 함정과 같은 종류).
