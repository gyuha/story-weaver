# RUN — 이어쓰기 후보를 JSONL로 받기 (형식 계약 + 4계층 관용 파서)

실행 형태: **직접 실행(워크플로우 아님).** 변경은 api 1파일 + web 1파일 + 테스트라 병렬 이득이 없다.
모드: `tdd: on`, `eco: on`. `Run all` 배치의 2/3번째(#64 → **#62** → #63).

## 계획대로 된 것

- **S1 백엔드 JSONL 계약 명시** — `prompt_assembler.py`의 `_TASK_INSTRUCTION[continue_]`에 `{"text":"후보 본문"}` 한 줄 형식과 금지 목록(번호·라벨·제목·머리말·설명·코드펜스·배열)을 추가했다. `title_`의 출력 형식 못박기 선례를 따랐다.
- **S1 누출 방지** — 다른 5개 태스크(`infill`·`dialogue`·`style`·`correct`·`title_`)의 지시에 `{"text"`가 없음을 파라미터 테스트로 고정. 단일 본문 반환 태스크가 JSON으로 오염되면 회귀다.
- **실제 모델로 준수 측정** — 조립된 **실제 프롬프트**로 3회 스트리밍 호출: 매회 4줄, **4줄 전부 유효 JSONL**(3/3 완전 준수). 지난번 "제가 만든 프롬프트로 테스트해 거짓 통과를 보고한" 실수를 반복하지 않기 위해 `assemble_prompt()` 산출물을 그대로 썼다.
- **S2 파서 4계층 교체** — `parseSuggestions`의 이름·시그니처를 유지하고 내부만 교체(소비자 코드 무변경). 계층: ① JSONL 줄 ② 코드펜스 벗긴 `{"candidates":[...]}` ③ 줄 시작 라벨(`**후보 N**`·`### 후보 N`·`N.`/`N)`) ④ 원문 1개.
- **S2 증분 파싱** — `parsePartialSuggestions`가 `split('\n')`의 **마지막 줄을 미완결로 간주**하고 그 앞의 완결된 JSONL 줄만 후보로 확정한다. 스트리밍 중 원문을 후보로 내보내지 않는다.
- **오분할 방지** — 일반 굵은 글씨(`**강조**`)·일반 제목(`## 소제목`)·인라인 라벨(`가 후보 2 나`)은 경계가 아님을 테스트로 고정. 라벨 정규식이 `후보`+숫자 조합 또는 맨 번호만, 줄 시작 앵커로 매치한다.
- **파서 테스트 20건 전면 재작성** — 번호 기반 단정은 이제 1급 계약이 아니라 **관용 계층 ③**으로만 성립한다. 통과시키려 번호 로직을 1급으로 남기지 않았다.
- **S3 통합 회귀** — 팝오버(소비자 2곳)·모달의 픽스처를 JSONL로 갱신. `suggestion-picker.test.tsx`의 취소·적용 테스트 2곳은 **의도적으로 `1. 가\n2. 나` 픽스처를 남겨** 관용 계층 ③을 실제로 태운다.
- **Non-goals 무침범** — `response_format` 미사용 · 다른 assist 태스크 무변경 · `dynamic_update` JSON 경로 무변경 · 후보 개수 `3~5개` 유지 · `---` 구분자 미지시·미관용 · 와이어 포맷 무변경 · 호출부 시그니처 무변경 · `.env` 무변경.

## 도중에 내린 결정 (플랜이 방법을 열어둔 부분)

- **파서를 "정규화 후 단일 경로"가 아니라 계층별 시도 순서로 구현했다.** 각 계층이 `null`을 반환하면 다음으로 넘기는 형태(`parseCandidatesObject(text) ?? parseByLabel(text) ?? [text.trim()]`)가 가장 짧고, 계층 간 의미 차이(JSONL·배열은 후보 목록을 직접 주고, 라벨은 경계를 준다)를 억지로 통합하지 않는다.
- **JSONL 계층은 "유효한 줄이 하나라도 있으면" 채택한다.** 깨진 줄은 건너뛴다 — 스트리밍이 중간에 끊겨 마지막 줄이 깨져도 앞의 후보를 살린다.
- **`text` 키가 빈 문자열이면 후보로 보지 않는다** — 빈 카드가 뜨는 것을 막는다.

## 계획과 달라진 것 (divergence)

- **테스트 픽스처 갱신 범위가 플랜 추정보다 넓었다.** 플랜은 "팝오버·모달의 기존 테스트를 새 형식 픽스처로 갱신"이라고만 적었으나, 실제로는 `suggestion-picker.test.tsx` 5곳 + `manuscript.test.tsx`의 스트리밍 점진 반영 테스트 1건까지 고쳐야 했다. 후자는 "마커 2개면 첫 후보만 확정"이라는 **구 증분 규칙을 주석까지 곁쇄**하고 있어 JSONL 규칙(개행이 경계)으로 다시 썼다.
- **biome 포맷 오류 1건** — 라벨 정규식이 줄 폭 100을 넘어 `lint:fix`로 자동 정리했다.
